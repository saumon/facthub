Core Features

Everything you need to manage and deliver curated facts at scale.

📚

Curated Fact Management

Create, organize, and maintain your fact collections through an intuitive admin interface. Import facts in bulk from markdown files with automatic deduplication.

🎯

Controlled Fact Delivery

Deliver facts sequentially to registered clients via a public REST API. Each client maintains its own independent progression through your fact collection.

📊

Client Progression Tracking

Monitor which facts each client has received, reset progression when needed, and assign human-readable aliases for easy identification.

⚡

Public REST API

Serve random or sequential facts via a clean JSON API. No authentication required for consumers — just register a client and start delivering.

📥

Bulk Markdown Import

Upload markdown files containing facts in bullet-list format. Automatic validation, deduplication, and background processing with live progress tracking.

🔒

Secure Admin Interface

Password-protected admin dashboard with session timeout, full CRUD for facts and clients, and a modern dark theme built for productivity.

Built for Content Teams

Whether you manage content, own the product, or build the integration — Fact Hub fits your workflow.

✍️

For Content Managers

Manage your fact library without touching code. Upload, edit, and organize facts through a polished web interface designed for efficiency.

🎛️

For Product Owners

Control the delivery experience. Decide how and when facts reach your audience with sequential delivery and per-client progression tracking.

🛠️

For Development Teams

Integrate in minutes with a clean REST API. Self-hosted with Ruby on Rails, SQLite storage, and zero external service dependencies.
